# PRD: 历史消息编辑重发与消息重新生成 (Chat & AgenticChat)

## 1. 背景与目标
在常规 AI 对话及 Agent 应用（如 ChatGPT、Claude、Dify 等）中，用户经常需要微调之前的提问或在回答不理想时重新生成。
当前 Memoria 在常规对话 (Chat.tsx) 和 Agent 对话 (AgenticChat.tsx) 中仅支持线性单向追加消息，无法对已发送的历史消息进行修改重发或重新生成回复。

本功能的目标是为 Memoria 补齐标准 Agent 应用的核心对话交互能力：
1. **用户历史消息编辑并重发**：用户可在任意历史提问上点击编辑，修改文本后重新发送，系统自动截断该节点之后的历史并重新触发流式回答。
2. **用户历史消息直接重发**：用户可一键重新发送某条历史提问。
3. **助手回答重新生成 (Regenerate / Retry)**：用户可对助手回答（尤其是最新回答或指定回答）一键触发重新生成，自动清理旧回答及后续消息并重新执行流式推理/Agent 执行。
4. **后端与数据库状态一致性**：截断操作同步持久化至 SQLite 数据库（清理被截断的消息与思维链 Traces），保证刷新或重连后上下文与界面完全一致。

---

## 2. 功能范围与用户故事

### 2.1 用户消息操作
- **悬停/常驻操作栏**：每条用户消息展示：
  - **编辑 (Edit)**：点击进入内嵌编辑模式。
  - **重发 (Resend / Retry)**：点击直接以该消息内容作为当前节点重新发送。
  - **复制 (Copy)**：一键复制消息文本至剪贴板，带临时成功反馈。
- **内嵌编辑交互**：
  - 消息气泡变为自适应多行文本输入框，带自动聚焦。
  - 底部提供 "发送" (Save & Send) 与 "取消" (Cancel) 按钮。
  - 支持键盘快捷键：Enter 提交，Esc 取消。
  - 提交时：截断该用户消息及其之后的所有消息与 Traces，以新文本替换并重新发起生成。

### 2.2 助手消息操作
- **操作栏增强**：每条助手消息底部展示：
  - **重新生成 (Regenerate)**：截断该助手消息及其之后的所有消息与 Traces，基于前面的对话上下文重新触发模型/Agent 生成。
  - **复制 (Copy)**：复制 Markdown 原始内容至剪贴板。
- **AgenticChat 专属保障**：
  - 重新生成时，清理该助手消息关联的思维链 (Traces)、工具调用记录与待审批/已审批状态，避免脏状态残留。

### 2.3 状态管理与互斥控制
- 当正在流式生成或 Agent 正在执行时，禁用编辑、重发与重新生成按钮，防止并发写冲突。

---

## 3. 非功能性需求
- **交互体验**：操作流畅无闪烁，文本自适应高度，按钮具备 Tooltip 提示与清晰视觉状态。
- **鲁棒性**：网络异常或服务端报错时，界面提供清晰 Toast / 错误提示，且不损坏前端已有状态。
- **跨页面统一**：Chat.tsx（Bot 普通对话）与 AgenticChat.tsx（通用 Agent 对话）保持统一的交互范式和视觉风格。

---

## 4. 验收标准
1. [ ] 用户在常规对话 (Chat) 中编辑历史提问并提交后，该提问及之后的旧消息被清除，界面展现新提问并流式输出新回答；刷新页面后消息列表与最新状态一致。
2. [ ] 用户在 Agent 对话 (AgenticChat) 中编辑提问或重新生成助手回答，旧回答的思维链、耗时、Token 统计被重置并重新执行 Agent 流程。
3. [ ] 用户点击复制按钮能成功复制文本并给予视觉反馈。
4. [ ] 流式生成中，操作按钮处于禁用状态；流式生成完成后恢复可用。
5. [ ] 后端单元测试覆盖会话消息截断与 Trace 清理逻辑，前后端构建/测试通过。
